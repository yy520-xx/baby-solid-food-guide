# 🍼 宝宝辅食添加指南 (Baby Solid Food Guide)

> 系统化的婴幼儿辅食添加时间表、食材引入顺序与过敏观察指南 —— 科学喂辅食，少走弯路。

## 📖 项目背景

宝宝 6 个月左右开始添加辅食，这是成长中的重要里程碑。但很多新手家长面对辅食添加常常一头雾水：

- 到底什么时候开始加辅食？
- 先加什么食材？后加什么？
- 每种食材观察几天？
- 出现什么反应算过敏？
- CMPA 宝宝有什么特别注意事项？

本项目整理了一套系统化的辅食添加指南，结合国内外权威指南和实际育儿经验，帮助家长科学、有序地完成宝宝的辅食引入过程。

## 🎯 项目目的

- 📅 提供清晰的辅食添加时间线，按月龄阶段划分
- 🔢 规范食材引入顺序，降低过敏风险
- 🚨 建立过敏反应观察与识别指南
- 🍽️ 提供各阶段的食物质地和烹饪方法建议
- 🏷️ 特别标注 CMPA 宝宝的注意事项

## 📋 内容概览

### 1. 辅食添加时间线 (`guides/introduction-timeline.md`)

从 4 个月准备期到 24 个月，按月龄阶段详细规划：
- 各阶段的辅食次数和量
- 推荐引入的食材类别
- 喂养工具和环境准备

### 2. 过敏原引入指南 (`guides/allergen-introduction-guide.md`)

- 常见八大过敏原引入顺序建议
- 每次新食材的观察期和记录方法
- 过敏反应的分级和应对措施
- CMPA 宝宝的特殊注意事项

### 3. 辅食安全检查清单 (`guides/food-safety-checklist.md`)

- 食材选购安全要点
- 制作和储存安全规范
- 危险食物黑名单
-  choking 风险食物处理

### 4. 食物质地进阶表 (`charts/food-texture-chart.md`)

- 从稀泥到家常饭菜的质地进阶路线图
- 各月龄推荐质地和代表食物

## 🚀 使用说明

1. **按月龄阅读**：找到宝宝当前月龄对应的阶段，按指南规划辅食
2. **打印速查表**：将 `charts/` 中的表格打印贴在厨房，方便日常参考
3. **记录观察日志**：每次引入新食材，使用观察记录表记录反应
4. **结合医生建议**：本指南为通用参考，具体方案请结合宝宝个体情况和医生建议
