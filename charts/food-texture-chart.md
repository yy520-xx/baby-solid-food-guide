# 🍽️ 食物质地进阶表

> 从稀泥到家常饭菜，按月龄推进的食物质地路线图。

---

## 📊 总览

```
稀泥 → 稠泥 → 碎泥 → 碎末 → 小丁 → 小块 → 家常饭菜
 4-6月  6-7月  7-9月  9-12月 12-18月 18-24月  24月+
```

---

## 🥣 阶段一：稀泥状（4-6 个月）

### 质地描述
- 像酸奶一样可以流动
- 完全无颗粒，用勺子舀起会自然流下
- 舌头和上颚就能压碎

### 代表食物
| 食物 | 做法 |
|------|------|
| 强化铁大米粉 | 加水/配方奶调稀 |
| 南瓜泥 | 蒸熟后加大量水打泥 |
| 胡萝卜泥 | 蒸熟打泥，过筛 |
| 苹果泥 | 蒸熟打泥 |

### 喂食要点
- 用勺子喂食，不装奶瓶
- 开始量少（1-2小勺），观察接受度
- 每天固定时间，培养规律

---

## 🥄 阶段二：稠泥状（6-7 个月）

### 质地描述
- 类似酸奶或米糊的稠度
- 有极细小的颗粒感，但基本顺滑
- 勺子舀起不会快速流下

### 代表食物
| 食物 | 做法 |
|------|------|
| 混合蔬菜泥 | 两种以上蔬菜混合打泥 |
| 红薯泥 | 蒸熟压泥，少量水调稠 |
| 牛油果香蕉泥 | 直接压泥，无需加水 |
| 小米粥（稀） | 煮烂后打匀 |

### 进阶要点
- 开始引入混合食材
- 逐步增加稠度，减少水分
- 每天 2 餐

---

## 🍲 阶段三：碎泥状（7-9 个月）

### 质地描述
- 有明显小颗粒（约米粒大小）
- 不是完全顺滑的泥，能感觉到颗粒
- 需要舌头配合牙龈碾碎

### 代表食物
| 食物 | 做法 |
|------|------|
| 蔬菜碎泥 | 蒸熟后用叉子压碎，不过筛 |
| 肉末粥 | 瘦肉末煮软，与粥混合 |
| 蛋黄泥 | 熟蛋黄压碎加温水调开 |
| 水果碎 | 香蕉用叉子压成小颗粒 |

### 进阶要点
- 引入蛋白质类食物（蛋黄、豆腐、肉末）
- 练习咀嚼动作
- 可以开始提供手指食物（软条状）

---

## 🍖 阶段四：碎末状（9-12 个月）

### 质地描述
- 米粒到绿豆大小的碎末
- 需要更多咀嚼动作
- 可以用牙龈磨碎

### 代表食物
| 食物 | 做法 |
|------|------|
| 软米饭 | 比成人米饭多加水，煮软 |
| 烂面条 | 煮到很软，剪短 |
| 碎菜粥 | 蔬菜切碎末加入粥中 |
| 手指食物 | 蒸软的胡萝卜条、土豆条 |

### 进阶要点
- 每天 3 餐 + 加餐
- 鼓励自主抓食
- 食物种类多样化

---

## 🍚 阶段五：小丁状（12-18 个月）

### 质地描述
- 约 5mm-1cm 的小丁/小块
- 需要咀嚼和研磨
- 接近成人食物的软质版本

### 代表食物
| 食物 | 做法 |
|------|------|
| 家常软饭 | 正常米饭即可 |
| 软馒头/面包 | 撕成小块 |
| 炒碎菜 | 蔬菜切小丁炒熟 |
| 肉丸/鱼丸 | 自制软嫩丸子 |

### 进阶要点
- 和家人同桌吃饭
- 使用儿童餐具
- 训练自主进食技巧

---

## 🍳 阶段六：家常饭菜（18-24 个月+）

### 质地描述
- 接近成人食物，但仍偏软、少调味
- 各种烹饪方式都可以尝试
- 逐步过渡到家庭饮食

### 注意事项
- 少盐少糖，清淡为主
- 避免过于辛辣刺激
- 注意食物大小，防止噎食
- 保证营养均衡

---

## ⚠️ 质地倒退信号

如果宝宝出现以下情况，可能需要暂时退回上一阶段质地：

- 作呕、呕吐频繁
- 食物含在嘴里不咽
- 明显抗拒进食
- 出牙期牙龈不适

---

## 📌 快速对照表

| 月龄 | 推荐质地 | 代表食物 | 每日餐次 |
|------|---------|---------|---------|
| 4-6月 | 稀泥 | 米糊、南瓜泥 | 1次 |
| 6-7月 | 稠泥 | 红薯泥、混合果泥 | 2次 |
| 7-9月 | 碎泥 | 肉末粥、蛋黄泥 | 2-3次 |
| 9-12月 | 碎末 | 软饭、烂面条 | 3次+加餐 |
| 12-18月 | 小丁 | 家常软饭、炒碎菜 | 3次+2加餐 |
| 18-24月 | 家常饭菜 | 家庭餐（清淡版） | 3次+2加餐 |
