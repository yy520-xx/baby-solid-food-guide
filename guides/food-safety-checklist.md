# ✅ 辅食安全检查清单

> 从食材选购到餐桌安全，全方位守护宝宝饮食安全。

---

## 🛒 食材选购安全

### 购买前检查

- [ ] **看配料表**：优先选择配料表短、成分简单的食品
- [ ] **看保质期**：不买临期或过期食品
- [ ] **看包装**：包装完整无破损、无膨胀
- [ ] **看认证**：婴幼儿食品应有对应的生产标准号
- [ ] **看年龄标注**：确认食品适合宝宝当前月龄

### 食材选择原则

- [ ] 蔬菜水果：优先应季食材，充分清洗去皮
- [ ] 肉类：选择新鲜、正规渠道购买，注意储存温度
- [ ] 鱼类：选择低汞品种（三文鱼、鳕鱼、鲈鱼）
- [ ] 加工食品：尽量少买，能自制就自制

### 🚫 不适合 1 岁以下宝宝的食材

| 食材 | 原因 |
|------|------|
| 蜂蜜 | 可能含有肉毒杆菌孢子，婴儿肠道无法抵御 |
| 盐 | 婴儿肾脏发育不完善，加重负担 |
| 糖 | 养成嗜甜口味，增加龋齿风险 |
| 鲜牛奶（作为主要饮品） | 蛋白质分子大，不易消化；铁含量低 |
| 整颗坚果/葡萄/圣女果 | 窒息风险，必须切碎或打泥 |
| 含咖啡因的饮品 | 影响神经系统发育 |
| 高汞鱼类（鲨鱼、旗鱼、金枪鱼） | 汞蓄积影响神经系统 |

## 👩‍🍳 制作安全

### 卫生规范

- [ ] 制作前彻底洗手，剪短指甲
- [ ] 生熟分开：生肉、蔬菜、熟食使用不同砧板和刀具
- [ ] 餐具消毒：每次使用前煮沸消毒或使用消毒柜
- [ ] 辅食制作工具专用：不与成人混用

### 烹饪要点

- [ ] 肉类必须彻底煮熟，无血水、肉质不粉红
- [ ] 蔬菜水果充分清洗，必要时用流动水冲洗
- [ ] 现做现吃最好，剩余辅食不超过 24 小时
- [ ] 不反复加热辅食，一次吃完最好

### 温度安全

- [ ] 喂食前务必试温：滴在手腕内侧，感觉温热不烫
- [ ] 微波炉加热不均匀，容易局部过烫，使用后需充分搅拌
- [ ] 冷藏辅食加热后中心温度应达到 70°C 以上

---

## 🗄️ 储存安全

### 冷藏储存

| 食物类型 | 冷藏时间 |
|---------|---------|
| 现做果泥/菜泥 | 24 小时内 |
| 熟制肉泥 | 12-24 小时 |
| 冷藏配方奶（已冲调） | 24 小时 |

### 冷冻储存

- [ ] 使用冰格或辅食分装盒冷冻
- [ ] 标注制作日期和食材名称
- [ ] 冷冻保存不超过 1 个月
- [ ] 解冻方法：冷藏解冻或温水浴解冻，不可室温解冻
- [ ] 解冻后不重新冷冻

### ⚠️ 危险信号（丢弃）

- [ ] 出现异味、变色、发霉
- [ ] 包装膨胀、漏液
- [ ] 解冻后超过 24 小时未食用
- [ ] 宝宝吃剩后再次回存（唾液污染）

---

## 🪑 进食安全

### 防窒息（Choking Prevention）

- [ ] 宝宝必须坐直进食，不可躺卧或斜靠
- [ ] 进食时全程有人看护，不边玩边吃
- [ ] 高窒息风险食物需特殊处理：
  - 葡萄、圣女果：切半去籽，再切四分之一
  - 整颗坚果：打泥或磨粉
  - 热狗/香肠：纵向切开再切丁
  - 硬糖、果冻：绝对禁止
- [ ] 进食时不逗笑、不惊吓
- [ ] 学习海姆立克急救法（婴儿版）

### 进食环境

- [ ] 使用专用宝宝餐椅，系好安全带
- [ ] 远离热源（热水杯、汤碗）
- [ ] 吃饭时不开电视、不玩手机
- [ ] 宝宝表示不想吃时不强迫

---

## 📋 外出就餐安全

- [ ] 外出前准备好自带辅食和零食
- [ ] 点菜时主动询问配料，避免隐藏过敏原
- [ ] 选择清淡、蒸煮类菜品
- [ ] 自带餐具和围兜
- [ ] 注意就餐环境清洁

---

## 🆘 紧急情况处理

### 发生窒息

1. 立即拍背：让宝宝俯卧在手臂上，头低脚高，用掌根在两肩胛骨之间拍 5 次
2. 如无效，翻转为仰卧，用两指在胸骨下半部快速按压 5 次
3. 重复以上步骤，同时呼叫急救
4. 如宝宝失去意识，立即开始 CPR

### 发生过敏反应

- **轻度**：停止可疑食物，观察，联系医生
- **中度**：尽快就医
- **重度**：立即拨打 120，如有肾上腺素笔立即使用
