# 🚨 过敏原引入指南

> 八大常见婴幼儿食物过敏原的引入顺序、观察方法与应对策略。

---

## 📋 八大常见食物过敏原

根据中国和国际过敏学会统计，婴幼儿最常见的八大食物过敏原为：

| 排名 | 过敏原 | 常见来源 | 过敏率（婴幼儿） |
|------|--------|---------|-----------------|
| 1 | 🥛 牛奶 | 配方奶、乳制品、含乳加工食品 | 2-3%（CMPA） |
| 2 | 🥚 鸡蛋 | 蛋黄、蛋白、烘焙食品 | 1-2% |
| 3 | 🐟 鱼类 | 海水鱼、淡水鱼 | 0.5% |
| 4 | 🦐 甲壳类海鲜 | 虾、蟹、龙虾 | 0.5% |
| 5 | 🥜 花生 | 花生、花生酱、含花生加工品 | 0.3-1% |
| 6 | 🌰 坚果 | 核桃、杏仁、腰果等 | 0.2-0.5% |
| 7 | 🌾 小麦 | 面包、面条、含麸质食品 | 0.5% |
| 8 | 🫘 大豆 | 豆腐、豆浆、豆制品 | 0.5% |

---

## 🎯 引入原则

### 核心原则：单一引入，逐一观察

每次只引入 **一种新食材**，连续观察 **3-5 天**，确认无异常后再引入下一种。

**为什么需要观察 3-5 天？**
- 速发型过敏反应（几分钟到2小时内）：通常较轻，易发现
- 迟发型过敏反应（数小时到数天）：可能表现为慢性湿疹、腹泻、反复吐奶
- 多观察几天可以更全面地捕捉到迟发反应

## 📅 推荐引入顺序

### 第一阶段（低风险、低过敏）
1. 强化铁大米粉
2. 南瓜、胡萝卜、土豆等温和蔬菜
3. 苹果、香蕉、梨等温和水果
4. 燕麦、小米等其他谷物

### 第二阶段（中风险）
5. **蛋黄**（从 1/4 开始）→ 逐步过渡到全蛋
6. 豆腐（大豆制品）
7. 小麦面食（面条、馒头）

### 第三阶段（高风险，谨慎引入）
8. 鸡肉泥
9. 猪肉泥
10. 红肉泥（牛肉、羊肉）
11. 低汞鱼类（三文鱼、鳕鱼）
12. 花生酱（稀释、少量）
13. 其他坚果酱（稀释）

> ⚠️ 高风险过敏体质宝宝（如家族有严重过敏史、已确诊 CMPA/湿疹），建议在医生指导下引入高风险过敏原。

## 👀 过敏反应观察指南

### 轻度反应（可观察，联系医生）

| 部位 | 表现 |
|------|------|
| 皮肤 | 局部红疹、轻度荨麻疹、湿疹轻微加重 |
| 肠胃 | 轻微呕吐、软便增加、轻度腹胀 |
| 口鼻 | 轻微口周发红、流涕 |

### 中度反应（尽快就医）

| 部位 | 表现 |
|------|------|
| 皮肤 | 全身散在荨麻疹、湿疹明显加重 |
| 肠胃 | 频繁呕吐、腹泻（含水样便）、便血 |
| 呼吸 | 鼻塞、打喷嚏增多、轻微咳嗽 |
| 精神 | 异常哭闹、烦躁不安 |

### 重度反应（立即就医/急救）

| 部位 | 表现 |
|------|------|
| 皮肤 | 全身大面积荨麻疹、面部肿胀 |
| 呼吸 | 喘息、呼吸困难、声音嘶哑 |
| 循环 | 面色苍白、嘴唇发紫、意识改变 |
| 肠胃 | 喷射性呕吐、严重腹泻 |

## 🏥 CMPA 宝宝的特殊注意事项

对于已经确诊牛奶蛋白过敏的宝宝：

1. **严格规避牛奶及所有乳制品**
   - 包括：鲜奶、奶粉、酸奶、奶酪、黄油、奶油
   - 隐藏来源：蛋糕、饼干、面包、奶茶、巧克力、人工调味料

2. **使用医生推荐的替代配方**
   - 轻度 CMPA：深度水解配方
   - 中重度 CMPA：氨基酸配方
   - 豆基配方需谨慎（10-15% CMPA 宝宝合并大豆过敏）

3. **交叉过敏风险**
   - 牛奶与羊奶、马奶交叉过敏率高（>90%）
   - 不建议自行用羊奶替代牛奶

4. **定期随访**
   - 每 6-12 个月复查牛奶蛋白耐受情况
   - 在医生指导下进行口服食物激发试验（OFC）
